# Conold Thando Chisinahama Portfolio

A privacy-conscious professional portfolio, case-study library, career profile, and living public-work index.

## Local development

```bash
npm install
npm run dev
```

Run the complete local gate with:

```bash
npm run verify
```

## Content safety

- Professional projects use sanitized names and fictional interface data.
- Private repository URLs, source code, commit messages, customer data, and credentials are never imported.
- Public-repository activity is allowlisted and refreshed through reviewable pull requests.
- New repository candidates remain unpublished until manually reviewed.

## Deployment

The intended production path is GitHub to Vercel. Pull requests receive preview deployments; `main` is the production branch.
